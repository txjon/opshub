Starting a new project

From Projects → + New Project
  1. Pick the client. Type in the search to find them. If they don't exist yet, click "+ New Client" and fill in the modal (name, type, default terms, billing address, primary contact).
  2. Set the project title — descriptive enough that anyone scanning the projects list knows what it is.
  3. Pick the job type (corporate / artist / tour / brand / webstore / drop_ship). Defaults from client type.
  4. Pick the shipping route:
    • Drop ship — decorator ships direct to client
    • Ship through — comes to HPD, immediately back out to client
    • Stage — comes to HPD, held as inventory until orders come in
  5. Set ship date. The in-hands date auto-suggests ship date + 3 days. You can override.
  6. Save. You land on the Product Builder tab.
Reorder shortcut: If a client is reordering, find the previous project → "Duplicate" button in the header. Items, contacts, costing all carry over.

Building the item list Product Builder tab

Adding items
Click + Add Item at the top of the sidebar. The Product Builder modal opens.

Catalog source picker — Favorites, S&S Activewear, AS Colour, LA Apparel, Other.
S&S flow: Pick brand → style → color → sizes. Costs and SKUs auto-fill.
Other / custom: For non-garment items (patches, stickers, totes, banners, etc.) use "Custom" — pick a garment type that maps to QB and enter the SKU manually.
Per-item fields
Each item gets a card. Click an item in the sidebar to select it.

Item name — header bar, click to edit. Keep it short and obvious ("Front Logo Tee", "Crew Sweat — Back Print").
Garment type — drives QB product mapping. Must be set.
Blank vendor / SKU / color — click the blank bar to change.
Sizes — enter qty per size. Tab / arrow keys move you across. Numbers auto-select on focus so typing replaces.
Dist button — type a total qty, hit Fill — it distributes across sizes using a smart curve (more M/L, less XS/3XL).
Notes — anything Drake needs to know about this specific item (color match request, special blank prep, etc.).
Sort order matters. Drag the ⠿ handle to reorder items. The order you set here is the order they appear on the quote, the PO, the invoice — everywhere. Letter designators (A, B, C…) follow this order across every tab.

Briefing the art /art-studio

Where art lives now
Art Studio is the single hub for every design brief — it replaced the old Art Files tab inside projects. Every brief is a visual tile with the latest version's thumbnail.

Brief states (in order):
StateWhat it means
DraftYou're building the brief, nothing sent yet
SentBrief is with the designer
In ProgressDesigner is working
WIP ReviewDesigner uploaded a work-in-progress for HPD to check
Client ReviewSent to client for approval
RevisionsClient requested changes
Final ApprovedClient signed off
Production ReadyPrint files prepped
DeliveredFiles sent to decorator
Your art workflow
  1. Upload client art. Drop files into the brief.
  2. Send brief to a designer (pick from the designer list). State moves to Sent.
  3. Watch the activity ribbon. When the designer uploads a WIP, you'll see a highlighted notice on the tile.
  4. Review the WIP with Drake if needed. Chat per-file in the brief modal.
  5. Forward to client for review. State moves to Client Review.
  6. Client approves on their portal. State moves to Final Approved automatically — you'll see a green ribbon on the tile.
  7. If client requests changes — state goes to Revisions, you send back to designer with notes, repeat.
Per-file chat is the central nervous system. Designer questions, client feedback, internal HPD notes — they all happen in the chat thread on each file. No more Slack scattergun.

Pre-order planning Ecomm — Pre-order Detail

Your role in the pre-order lifecycle: Planning phase
Pre-orders are scoped by you and Drake together, then handed off to Abigail to build in Shopify. You own the Planning phase.

On a pre-order in Planning, you:
• Add each product — name, blank vendor, blank SKU, sizes, retail price (what the client charges the end customer)
• Set lifecycle dates — Open date, Close date, Target ship date. Use the quick offset buttons (+3w / +4w / +5w / +6w) to set target ship from the close date.
• Set buffer % — defaults to 5-7%. This is how much extra qty you order over what Shopify sold, to cover damages and reprints.
• Add notes — anything Abigail needs to know about the build.

When you're done, click "Hand off to Abigail (Build in Shopify)". Status moves to Building — Abigail takes it from here.
See the Pre-order SOP for the full lifecycle and edge cases. Find it on the References page (lightbulb icon).

Handing off to Drake

Once a project has items, sizes, art briefed (or art in progress), and ship date set, it's ready for Drake to cost.

Drake will: Set decorator + print locations + finishing → margin → Lock In Pricing. Then quote, blanks, PO, production.

You can keep working on the art in parallel. Drake doesn't need final art to start costing — he just needs to know print count and complexity.
