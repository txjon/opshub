Costing the project Costing tab

Two panels per item
Blanks (left): Supplier picker, fleece toggle, per-size cost grid, item notes, item financial summary (Revenue, Blanks Cost, PO Total, Net Profit, Margin, Profit per Piece).

Decoration (right): Decorator picker, print locations table, tag print row, finishing & packaging, setup fees, specialty options, custom costs.
Print locations
Up to 6 print locations per item — typical: Front, Back, Left Sleeve, Right Sleeve, Left Chest, Right Chest, Neck, Hood, Pocket.

For each location: Position, Color count, Method (defaults to screen_print), Specialty if applicable (puff, glitter, foil, etc.).

Shared screen toggle — if multiple items use the same artwork at the same position, mark them with the same Share Group name (e.g. "A"). The system:
• Combines their qty for the price tier lookup
• Charges screen fees only once across the group
• Splits the cost across items proportionally
Margin tier & sell price
Pick a margin tier (10 / 15 / 20 / 25 / 30%) in the project totals sidebar. The sell price calculates automatically.

To override per-item, click "override" next to the sell price. Type the custom price. The override sticks even if you change the margin tier later.

Pricing source of truth: items.sell_per_unit — set here, read by every other surface (quote, invoice, portal, dashboard). No surface recalculates.
Lock In Pricing is required to unlock the Quote tab. After locking, inputs go read-only. Click Unlock Pricing to make changes — intentional friction so changes are deliberate.

Sending the quote Quote tab

  1. Review the quote preview — items, sizes, pricing, tax, total. Download PDF if you want to inspect.
  2. Click Send Quote → email dialog. Pick the recipient(s) — defaults to primary contact.
  3. Send. The quote PDF attaches. Email body includes the client portal link.
  4. Watch for approval. When the client clicks Approve on their portal, the Quote tab updates with "Approved on [date]" and the project advances to Pending or Ready.
  5. If rejected: The Dashboard surfaces a red alert with their rejection notes. Address them and re-send.
Tip: If the client wants minor changes ("add tote bags"), unlock pricing → adjust → re-lock → re-send. The Quote tab logs each send.

Proofs & invoice Proofs & Invoice tab

Proofs (top section)
Each item has files at different stages: client_art → vector → mockup → proof → print_ready.

Generate proofs: When an item has a mockup, click Generate Proof on that item → creates a proof PDF using the brand template + item details.

Send proofs to client: One consolidated email with a portal link to the proof viewer. The client approves or requests revisions on the portal.

For bulk-generate across all items, use the Approvals tab → Generate All button.
Invoice (bottom section)
Click Create QuickBooks Invoice (HPD) or Create Stripe Invoice (IHM). The system:
• Matches the client to the QB/Stripe customer (auto-searches by name)
• Maps each item's garment_type to a QB Product/Service
• Uses sell_per_unit × qty as the line rate
• Generates a payment link
• Reads back the calculated tax

Send Invoice emails the client with the PDF + payment link.
Send Invoice + Proofs combines both into a single email.
Variance review: If shipped qty differs from quoted qty, OpsHub flags the invoice as stale. Click the variance banner to review and push an updated invoice to QB/Stripe.

Ordering blanks Blanks tab

The 3-gate checklist
Before you can order, three gates show at the top:

✓ Quote approved
✓ Payment received (or N/A for net terms)
✓ All proofs approved

Net 15 / Net 30 terms auto-pass the payment gate. Prepaid and deposit_balance need at least one paid record.
Per-item entry
For each garment item (patches/stickers/totes are filtered out):
• S&S order number
• Total cost (compared against the calculated blank cost in Costing)

S&S sync button — auto-fills from your connected S&S account when possible.
Bulk apply — multi-select items + enter one total cost → distributed proportionally by costing ratio.

Sending POs PO tab

Per-vendor structure
POs group by decorator. Each vendor gets its own accordion with the items assigned to them.

Per-vendor ship date — calendar or ASAP. Drives lead time math.
Per-vendor ship-to address — defaults to HPD warehouse (4670 W Silverado Ranch). Override if needed (drop ship → client address, event drop → venue).
Shipping method — UPS, FedEx, USPS, Freight, Will Call, Decorator Drop Ship. UPS PO orders auto-use HPD's shipping account.
Per-item fields
FieldWhat it's for
Production files linkAuto-fills from print-ready file in Art Studio. Decorator clicks to grab files.
Incoming goodsNotes about blanks arriving ("S&S 123456 expected Tuesday")
Production notesSpecial instructions ("print under collar tag", "wash before print")
Packing / shipping notesPack per box by size, label boxes, etc.
Use "↓ Copy to all" next to any field to spread a value across all items for the current vendor.
Sending the PO
  1. Preview PDF. Check bill-to, ship-to, line items, dates, notes.
  2. Click Send. Email dialog opens with all decorator contacts checked.
  3. Send. The PO PDF attaches. OpsHub stamps type_meta.po_sent_vendors so the project knows this vendor's PO went out.
  4. The vendor portal link is auto-included so the decorator can confirm receipt + enter tracking later.

Tracking production /production

Production page (cross-project)
This is your daily home. Shows every project with items currently at decorators, plus recent shipments.

Filters: Search, decorator, stalled-only toggle (7+ days at decorator).

Stats strip: Items needing blanks ordered · waiting on proofs · stalled · shipping this week.

Click a project → opens a full-page modal. Items grouped by decorator. Each row shows the item, sizes, ordered qty, shipped qty (from vendor), received qty (at HPD), tracking, notes.
When a decorator ships an item
  1. Click Ship on the item row in the Production modal.
  2. The Ship modal opens. Enter tracking number. Adjust per-size shipped qtys if different from ordered.
  3. Optionally upload a packing slip (drag-drop PDF or image).
  4. Add ship notes (e.g. "shorted 4 mediums, will follow up").
  5. Click Mark Shipped.
Batch ship — multiple items, one shipment
If a decorator puts multiple items in one box with one tracking number:

Select items via checkboxes → click "Ship Selected · N" → one tracking, one packing slip applies to all. Saves you N round trips.

When items ship

What happens after Mark Shipped
RouteWhat happens
Drop shipClient notified automatically (production_complete email with tracking). Item completes when received.
Ship throughGoes to /receiving for warehouse. Client is NOT notified yet — warehouse handles client comms when they ship outbound.
StageGoes to /receiving. Eventually entered into Shopify by Abigail, then fulfilled from ShipStation as orders come in.
Notify Recipient dialog opens after Mark Shipped. The dialog routes the email correctly based on shipping route — drop_ship goes to client, ship_through skips. Choose contacts and confirm.

Pre-order push-to-production

When Abigail closes a pre-order in /ecomm, the project moves to "Closed · pending push". You take over from there.

Open the pre-order → click Push to Production. The wizard:
• Shows each product with per-size inputs
• You paste the sold qtys from the Shopify report
• Applies the buffer % (default 5-7%, editable per pre-order)
• Calculates the total ordered qty per variant (rounds up)
• Shows the grand total
• On confirm, creates a new Labs job with shipping_route="stage", pre-fills items + buy_sheet_lines, links back to the pre-order

The new Labs job opens in a new tab. From here it's a normal stage job — cost, blanks (if not already done), PO, production.
See the Pre-order SOP for the full lifecycle and ownership map. Available on /references.
