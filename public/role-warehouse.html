Receiving — inbound boxes /receiving

How boxes are organized in OpsHub
Items group into shipments — one row per physical box (matched by decorator + tracking number). When a decorator ships 3 items in one box, you see one row for the box, not three separate items.

Three tabs:
TabWhat's in it
PendingShipments in transit, awaiting your receipt
ReceivedCompleted receives + recently-shelved Shopify inventory
OutsideAd-hoc third-party shipments (someone dropped off blanks, samples, etc.)
When a box arrives
  1. Find the shipment on the Pending tab. Search by tracking, decorator, or client if needed.
  2. Click the row → opens the receive modal with every item in that box.
  3. For each item, enter the per-size received quantity (defaults to what was shipped — adjust if different).
  4. If you pulled any units as samples (QA, photoshoot, client comp), enter the sample quantity per size.
  5. Set the condition — Good / Damaged / Other. Add notes if damaged or short.
  6. Upload packing slip photos and any other documentation (drag-drop).
  7. Click Mark Received. The shipment moves to the Received tab.
Variance alerts: If received qty is less than ordered qty, OpsHub flags the variance automatically. Add a note about why (short shipment, damage, missing box) and OpsHub surfaces it on the project for Drake to follow up.

"Live in Shopify — shelve" Received tab

The Received tab has a pinned section at the top called "Live in Shopify — shelve" with a green left rail.

This section shows shipments that:
• Were stage-route (held inventory for a Shopify store)
• Got entered into Shopify by Abigail
• Are within a 48-hour window after entry

Your job: Physically organize these boxes onto shelves so ShipStation can pick from them. Once you've shelved everything, you don't need to do anything in OpsHub — the section auto-rolls off after 48 hours.
Why the 48-hour window: When Abigail says "this is live in Shopify", that means customer orders can start coming in any minute. You have a tight window to get the physical inventory shelved so ShipStation pickers can find it.

Shipping — outbound /shipping

What's on this page
Ship-through projects that are fully received at HPD and ready to go out to the client.

Tabs:
• Ready to Ship — projects awaiting outbound
• Shipped — audit history (last 30 days, then collapsed older)
When you ship a ship-through project
  1. Find the project on the Ready to Ship tab.
  2. Click the row → opens the Ship modal with all items.
  3. Review ship-to address, recipient contact, any shipping notes.
  4. Confirm which items are shipping (all selected by default — uncheck any that aren't going with this shipment).
  5. Enter outbound tracking number.
  6. Click Mark Shipped. The Notify Recipient dialog opens.
  7. Pick the client contact(s) to email. Defaults to the project's primary recipient. Send.
Looking up a past shipment
Switch to the Shipped tab. Use the date buckets (Today / Yesterday / This week / Last 30 / Older). Click any row for a read-only detail modal with tracking, ship date, packing slip link.

Fulfillment — read-only view /fulfillment

Chronological feed of stage-route shipments received over the last 30 days. Read-only — you don't take action here, you just see what's coming in and whether front office (Abigail) has entered it into Shopify yet.

Each row's left rail color tells you the status:
• Green — all items entered in Shopify (ready to shelve)
• Amber — partial (some items still pending)
• Faint — pending front-office entry

Click any row for a detail modal showing what's been entered and what's still pending.

Silent Mode

When to use it
Both /receiving and /shipping have a Silent Mode toggle in the top-right of the page.

When OFF (default):
• Receiving — Mark Received triggers the "production complete" email to the client (if drop-ship or ship-through route)
• Shipping — Mark Shipped opens the Notify Recipient dialog → sends outbound tracking email to client

When ON:
• Both stay silent — no automatic client emails fire

Use silent mode when:
• Backfilling old shipments (you don't want to spam the client about a project from 2 weeks ago)
• Test entries
• Any case where you've already communicated with the client outside OpsHub
Default state: Silent Mode is OFF when you load the page. It saves your last choice in your browser, so if you turn it on, it stays on for that browser until you turn it off again. Always check the toggle before bulk-marking shipments.
