Daily review loop

The 5-minute morning
  1. Dashboard — scan KPIs and red alerts. Anything in the red bucket needs eyes today.
  2. Stalled production — /production stalled-only toggle. Items 7+ days at a decorator. Follow up with Drake / vendor.
  3. Outstanding payments — Dashboard or Reports. Anything overdue triggers a follow-up email.
  4. Recent rejections — Quote rejected? Proof revisions requested? Show on the Dashboard. Make sure Drake / Taylor are on it.
  5. Capacity check — How many projects in Production phase? Anything pushing the team's bandwidth?

Payments oversight

Two providers, one mental model
TenantProviderWhere payments live
HPDQuickBooksQB invoices, QB payment webhooks → OpsHub
IHMStripeStripe invoices, Stripe webhooks → OpsHub
Every paid invoice flows through a webhook that records the payment in OpsHub and updates the project + dashboard automatically.
When a payment doesn't auto-register
Sometimes the webhook misses (provider issue, network blip, signature mismatch). Symptoms:
• Invoice is paid in QB / Stripe
• Project still shows unpaid
• Dashboard alert still says "follow up on payment"

Fix:
1. Go to the project → Proofs & Invoice tab → Payments section
2. Click + Add payment record
3. Set type (deposit / balance / full), amount, invoice number, status = paid
4. Save. Project recalculates, dashboard alert clears.
QB webhook health
QB requires a CloudEvents migration by 2026-05-15. Confirm /api/qb/webhook2 is migrated to webhook3 (CloudEvents format) before the deadline. Test via Intuit's switch button before cutover.

Team management /settings

Inviting team members
  1. Settings → Team → + Invite member.
  2. Enter email, name, role (viewer / staff / manager).
  3. Pick department access (Labs / Distro / Ecomm / Contacts / Settings).
  4. Send. Supabase fires the invite email.
  5. New user sets password on first login, lands on their default department.
Roles
RoleCan do
ViewerRead-only across granted departments
StaffStandard work — create projects, cost, ship, etc.
ManagerEverything staff can do + Settings, Reports, Insights, team invites
Click any user's role in the team table to change it. You can't change your own role (prevents lockout).

Multi-tenant operations

HPD and IHM
OpsHub serves two companies via subdomain routing:
• HPD (House Party Distro) — Las Vegas custom apparel
• IHM — touring artists / bands brand

Each tenant has its own clients, decorators, payment provider, and team. RLS enforces strict separation — no data crosses tenants except where explicitly modeled (e.g. cross-tenant warehouse fulfillment).

The active tenant shows as a small slug under the sidebar logo (HPD or IHM).
Cross-tenant warehouse (planned)
IHM can use HPD as its fulfillment partner. The architecture supports surfacing IHM ship-through items on HPD's /receiving page via fulfillment_partner_company_id + a targeted RLS carve-out. Plan locked, in build.
