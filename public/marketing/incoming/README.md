# Photo staging

Drop raw photos here. Claude reads them, picks the best fits, renames
them descriptively, and moves them up to `/public/marketing/`. Anything
dropped in this folder is `.gitignored` — only the README + .gitignore
are tracked.

Workflow:
1. Drop photos in this folder
2. Tell Claude they're here
3. Claude sorts → moves → wires them up → cleans up the folder
